# 求职定位

## 目标岗位与主线

1. **Java 后端开发**：第一优先级，也是当前最熟悉、最应重点投递的方向。简历主线应优先呈现业务后端、数据处理、接口与系统工程能力。
2. **AI 应用开发**：第二优先级。企业知识库 RAG 系统是核心素材，只有在业务场景、本人贡献和验证范围核实后，才具体写 RAG、Agent 等能力。
3. **AI 开发**：第三优先级。当前主要表达 AI Coding、AI 辅助软件研发和跨领域交付，不默认指模型训练或算法研究岗位。

整份简历以 Java 后端能力为主，以 AI 应用开发形成差异化，以 AI Coding 体现研发方法和交付能力。“AI Coding 能力较强”必须逐步落实为需求拆解、方案取舍、代码审查、排错、测试和交付证据，不写缺少依据的排名式评价。

## 经历分工与顺序

当前简历安排为一段实习、两个主力项目和一个补充项目：

1. **河南中烟卷烟厂卷包车间生产执行系统后端重构实习**：最重要。约三个月，以普通实习生身份表达，优先围绕约两条核心业务线组织约六条贡献；不能写成整个系统负责人。
2. **EMG 多端训练标注数据平台**：主力项目，重点体现 Java 后端。独立开发的 EMG 数据采集 Android App 不单列；只有核实实际接入和数据流后，才在平台背景中简短提及。
3. **企业知识库 RAG 系统**：主力项目，兼顾 Java 后端与 AI 应用开发。项目名称和亮点等代码核查后再定，不凭概念包装。
4. **sEMG 实时手部姿态推理系统**：补充项目，放在最后，最多约三条。以 Python 为主，用于体现 AI Coding、跨领域和完整系统交付；“端到端”指数据、推理、状态管理、GUI、服务等链路，不等于从零训练模型。

实习和前三个主要经历重点展开，补充项目不能挤占主力经历的篇幅。项目事实、职责和证据只在对应项目文件中维护，本文件只保存整体分工。
